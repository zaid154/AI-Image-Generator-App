# 🎨 AI Image Generator App

> A full-stack AI image generation web application built with **React**, **Node.js**, **Express**, and **OpenAI API**. Turn creative textual prompts into high-resolution visual artwork with real-time feedback and instant download capabilities.

## 🌟 Key Features

- 🧠 **Natural Language Prompting**: Generate intricate, high-quality images from descriptive text prompts.
- ⚡ **Real-Time Generation**: Asynchronous backend communication with OpenAI image generation tools.
- 🖼️ **Interactive Image Preview**: Sleek card display with high-resolution image viewing and aspect ratio preservation.
- 📥 **One-Click Download**: Seamlessly download generated artwork directly to your local device.
- 📱 **Mobile & Desktop Responsive**: Clean and modern user interface optimized for all screen sizes.

## 🛠️ Technology Stack

| Layer | Technologies Used |
|---|---|
| **Frontend** | React.js, Vite, Modern CSS3, Lucide React Icons |
| **Backend** | Node.js, Express.js (REST API Architecture) |
| **AI Integration** | OpenAI API (DALL-E / GPT Image Generation) |
| **Security & Utilities** | CORS, Dotenv, Async Error Handling |
